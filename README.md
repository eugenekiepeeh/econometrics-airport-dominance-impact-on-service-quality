# Econometric Analysis: Airport Dominance Impact on Service Quality

An econometric research project investigating the relationship between airport market dominance and service quality metrics.

## 📋 Overview

This repository contains a comprehensive econometric analysis examining how dominant carriers and airport concentration affect service quality. The project integrates data processing, statistical modeling, academic writing, and presentation materials.

## 📁 Project Structure

- **`00_data/`** — Raw and processed datasets used in the analysis
- **`01_scripts/`** — R and other scripts for data processing and econometric modeling
- **`02_paper/`** — Academic paper written in LaTeX
- **`03_presentation_slides/`** — Presentation materials for research findings
- **`04_output/`** — Generated results, figures, tables, and model outputs

## 🛠️ Technologies

- **R** — Primary language for statistical analysis (see `.Rproj`)
- **LaTeX** — Academic paper typesetting
- **Git** — Version control

## 📊 Key Components

### Data Processing (`00_data/`)
Handles acquisition and preparation of airport and carrier service quality datasets.

### Statistical Analysis (`01_scripts/`)
Contains scripts for:
- Exploratory data analysis
- Econometric model estimation
- Robustness checks
- Visualization generation

### Academic Output (`02_paper/`)
Full research paper documenting:
- Literature review
- Methodology
- Empirical results
- Conclusions and policy implications

### Dissemination (`03_presentation_slides/`)
Presentation materials for conferences, seminars, or departmental presentations.

## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/eugenekiepeeh/econometrics-airport-dominance-impact-on-service-quality.git
   cd econometrics-airport-dominance-impact-on-service-quality
   ```

2. **Open the R project:**
   - In R/RStudio, open `econometrics-airport-dominance-impact-on-service-quality.Rproj`

3. **Run the analysis:**
   - Execute scripts in `01_scripts/` to reproduce the analysis and generate output in `04_output/`
